# GenAcademy-P1-VibeCoding

## Jenkins Deployment Audit Dashboard

A Streamlit dashboard that summarizes Jenkins deployments from `jenkins-data.csv` for audit purposes:

- KPI cards: total deployments, successes, failures, other (aborted/unstable), success/failure %, average duration
- Charts: outcome donut, outcomes per user, monthly trend with success %
- **Monthly deployment summary by user** (`Started by | Jan … Oct | Total`) with a Grand Total row, a heat-map, and CSV/Excel export
- Failure audit detail (failure % per user and a list of every failed build)
- AI audit summary generated by Claude from aggregated statistics (optional)

### Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Enable AI summaries (optional)

Set an Anthropic API key in either place:

- environment variable `ANTHROPIC_API_KEY`, or
- `.streamlit/secrets.toml`:

  ```toml
  ANTHROPIC_API_KEY = "sk-ant-..."
  ```

Without a key, the dashboard works normally and the AI section shows a setup hint. Only aggregated figures are sent to the API, never the raw rows.

### Data

Expected CSV columns: `Build #`, `Result`, `Building`, `Duration (ms)`, `Timestamp (ms)`, `Start Time (UTC)`, `Duration (min)`, `User`.
Builds with `Building = TRUE` are excluded from counts. Use the sidebar uploader to load a newer export.
